# 2026-07-04 工作日志

## ES HTTP 500 错误诊断

**问题**：Spring Boot 启动时 ES 报 HTTP 500 Internal Server Error

**根因**：Cpolar 内网穿透工具（PID 9204）占用了 9200 端口，导致：
1. ES Docker 容器无法绑定 9200 端口，启动失败（Exited 137）
2. Spring Boot 配置 `spring.elasticsearch.uris: http://localhost:9200` 实际连到 Cpolar 而非 ES
3. `@PostConstruct initDate()` → `importAll()` 往 Cpolar 发 ES REST API 请求 → 返回 500

**已排除的问题**：
- IK 分词器：已安装（日志 `loaded plugin [analysis-ik]`），非分词器缺失
- 安全认证：`xpack.security.enabled=false`，非认证问题
- ES 本身：历史日志显示集群曾正常 YELLOW 运行，products 索引恢复成功

**解决方案**：关闭 Cpolar 或改其端口 → `docker start es` → 验证 `curl localhost:9200` 返回 ES JSON
