⚡ 核心业务流程

秒杀抢购 高并发 Redis Lua + MQ 异步 + 死信兜底

[1] 限流拦截器 RateLimitInterceptor (Lua 滑动窗口: 全局1s/100, 用户60s/5, IP 60s/10) [2] 验证码校验 → Redis 60s TTL [3] 秒杀令牌 UUID, Redis 60s TTL, 消费即删除 [4] seckillBuy() 核心逻辑: ├─ 校验秒杀券 (type=3, status, 时间窗口) ├─ Redis DECREMENT 预扣库存 (seckill:stock:{couponId}) ├─ 防重: 查 user_coupon + DB 唯一索引兜底 ├─ 雪花算法生成订单号 ├─ 写 seckill_event 事件表 (状态 0=待发送) ├─ 发 MQ → seckill.order.exchange └─ 异常时 Redis INCREMENT 回滚库存 [5] SeckillOrderConsumer 异步消费: ├─ Redis SETNX 幂等预检 (5min TTL) ├─ 手动设置 SecurityContext (MQ 无 HTTP 上下文) ├─ 调用 orderService.createOrder() └─ 更新事件状态 2=已完成 [6] 重试耗尽 → 死信队列 seckill.order.dead.queue → 人工补偿

支付与超时取消 RabbitMQ 延时队列

[1] createPayment() 校验订单 → 幂等检查 → 创建支付记录 → 发 15min 延时消息 [2] 用户完成 Mock 支付 → handleCallback() 幂等更新 → 订单 status=1 [3] 15min 未支付 → RabbitMQ TTL 过期 → order.timeout.queue [4] OrderTimeoutConsumer → 查订单状态仍为 0 → 自动取消 + 回滚库存

AI 对话 Spring AI + RAG + Function Calling

[1] AiService.chat(message, chatId) ├─ 首次对话 → 创建 AiConversation (标题取前20字) └─ 已有对话 → 更新 updatedAt [2] ChatClient 调用 LLM (Qwen-Plus via DashScope): ├─ MessageChatMemoryAdvisor → 按 chatId 恢复对话历史 (窗口20条, JDBC 持久化) ├─ QuestionAnswerAdvisor → RAG 检索 (相似度>0.75, TopK=3, Redis 向量库) └─ Function Calling → 自动调用 ProductTool / PostTool [3] 流式返回 Flux<String> → SSE 推送前端 [4] 知识库上传 → TokenTextSplitter 切分 → Embedding → Redis 向量存储

⚠️ 安全与代码质量观察

P0 - 敏感信息泄露（建议立即处理）
  • application.yaml 明文暴露 API Key：阿里云 DashScope 的 sk-ws-... API Key 直接写在配置文件中，若代码库公开将造成泄露。建议迁移到环境变量或密钥管理服务。
  • 数据库密码明文：MySQL 密码 123456 硬编码在配置中。
  • JWT Secret 过弱：abcdefghijklmnopqrstuvwxyz1234567890... 是可预测的弱密钥。
  • 管理员密码明文：admin 密码 admin123 明文存储（配置注释中也提到了生产环境应改 BCrypt）。
P1 - 权限配置问题
  • /api/shop/coupons/my 权限过宽：SecurityConfig 中将该 GET 端点设为 permitAll()，但"我的优惠券"应需登录认证。未登录用户访问会因 SecurityContext 无 userId 而出错或返回空。
  • 商品管理接口缺乏管理员校验：POST /api/shop/products、PUT /api/shop/products/{id}、DELETE 等写操作仅要求登录（authenticated()），未校验 ADMIN 角色，普通用户也能增删改商品。
  • POST /api/shop/orders/{id}/ship 发货接口：注释标注"管理员"，但实际权限配置为普通登录即可调用。
P2 - 代码规范与一致性
  • DTO 命名不统一：存在 LoginFrom、CommentCreateFrom（From）与 RegisterForm、ProductForm（Form）混用，建议统一为 Form。
  • @Operation 注解未覆盖：Admin 系列 Controller、SeckillController、PaymentController、AiController 未添加 @Operation 注解，Swagger 文档不完整。
  • AGENTS.md 文档过期：文档中模块描述缺少 admin 后台管理、秒杀、优惠券、支付、物流、库存等模块，与实际代码不符。
  • SeckillController 缺少 SeckillForm：/api/shop/seckill/buy 引用了 SeckillForm，需确认该类是否存在。
