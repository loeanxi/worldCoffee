现状问题优化方案体验位置
首页下滑后左栏只剩尾部、右栏早早结束，两侧大片空白 左右栏改为「整屏高粘性」：左栏 flex 撑满视口、footer 沉底，并补「本周足迹 / 每日签到」填充垂直空间；右栏粘性 + 栏内细滚动条，模块永远陪跑信息流 首页 向下滚动观察两侧
频道 Tab 随页面滚走，想换频道必须回顶部 Tab 栏吸顶 + 毛玻璃背景，滚动中随时切换频道（原型中 Tab 真实过滤瀑布流） 首页 滚动后点 Tab
瀑布流卡片静态无反馈，点赞/收藏要点进详情 卡片悬停上浮 + 图片微缩放 + 底部渐变浮层快捷操作（赞 / 藏 / 分享），点赞心跳动画与计数即时更新 首页 悬停任意卡片
右栏内容单薄，品牌卡之后无任何收尾 新增「每日冷知识」渐变卡（可换一条）+ 品牌卡下补条款/隐私/版权微链接，右栏信息密度与温度同时提升 首页 右栏中部
商城顶部分类为纯文字 Tab，层级弱、无引导 品类图标胶囊入口条（全部/咖啡豆/器具/杯具/周边），选中态深棕渐变，真实过滤商品 商城 顶部品类条

筛选面板滚走即失效，用户不知道筛出了多少 筛选面板吸顶 + 栏内滚动；底部实时显示「已选 N 项 · 命中 M 件」；一键重置 商城 左栏
商品卡图片比例不一、无评分、加购无反馈 统一 1:1 图 + 悬停缩放与收藏按钮；补星级评分 / 已售 / 划线价；加购触发购物车徽章弹跳 + Toast 商城 任意商品卡

上手体验清单 建议按顺序点一遍

1首页滚动向下滚动 2 屏：左栏整屏陪伴、右栏栏内滚动、Tab 吸顶毛玻璃、右下回到顶部按钮浮现。
2首页 Tab滚动状态下直接点「拉花 / 豆子 / 咖啡馆」，瀑布流即时过滤并带上浮动画。
3卡片悬停悬停帖子卡：上浮 + 图片缩放 + 浮层出现；点 ♥ 看心跳与计数 +1。
4右栏互动点「换一条」切换冷知识；点创作者「关注」变「已关注」；左栏点「签到」。
5商城筛选勾选烘焙度 + 产地 + 价格，观察左栏命中数与商品网格实时变化；点「重置」复原。
6商城排序视图点「价格从低到高」再点右上 ☰ 切列表视图；悬停商品卡点 ♥ 与「加入购物车」看徽章弹跳。
